# TechStore

## Overview

TechStore is a personal full-stack e-commerce project developed to study professional backend development using Java and Spring Boot.

The project focuses on building a real-world application while applying software engineering principles such as object-oriented programing, database modeling, REST APIs, authentication, testing, and cloud deployment.

The objective is to understand not only how to build software, but also why archtectural decisions are made throughout the development process.

---

## Goals

- Improve Java and Spring Boot skills.
- Practice relational database modeling.
- Apply object-oriented design principles.
- Build a production-style REST API.
- Learn moder backend architecture.
- Create a protfolio-quality project.
